# Demo assets

`chat-prompt-demo.mp4` — a 3-second clip of the Content OS chat composer
typing a sample prompt ("Suggest 5 content ideas for this week"). Generated
from `scripts/chat-prompt-video/mockup.html` via
`scripts/chat-prompt-video/record.mjs`; rerun that script to regenerate it
(requires the `playwright` and `@ffmpeg-installer/ffmpeg` devDependencies,
plus `npm install`).
